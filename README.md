# The Acceleration Question — AI and Civilisational Change

An evidence-labelled, standalone report on what AI is measurably changing, what is inference, and what is speculation. Every claim is tagged BLUE (fact), PURPLE (interpretation), OCHRE (uncertainty/speculation), RED (risk/weakness) or GREEN (action/opportunity).

- **Read:** `index.html` (single file, works offline, prints cleanly, no trackers or external resources). Live page: https://nermalwazza.github.io/ai-acceleration-report/
- **Appearance:** choose Light, Dark or System on the [portfolio homepage](https://nermalwazza.github.io/portfolio/). This report follows the same saved browser preference, including when already open in another tab.
- **How figures were checked:** [Verification_Summary.md](Verification_Summary.md) (2026-10-16), including what was removed or still unverified.
